# AI Guard Documentation (English)

This directory is reserved for English documentation. The primary documentation is currently maintained in Chinese.

**Summary:** AI Guard is a Chrome/Firefox Manifest V3 extension that scans text typed into AI chat inputs for secrets and sensitive phrases, highlights matches, warns the user, and can block sending. Detection runs entirely locally, with no telemetry, remote code, or network requests. Rules and site adapters are configurable.
