AI Guard — Privacy Policy

Last updated: September 2026

Overview

AI Guard is a browser extension that detects sensitive content in AI chat inputs. We are committed to protecting your privacy.

No Data Collection

AI Guard does not collect, store, or transmit any personal data or usage information to external servers. Specifically:

  • No browsing history is collected or uploaded
  • No typed text or input content is sent to any server
  • No analytics, tracking, or telemetry is performed
  • No cookies or identifiers are created for tracking purposes

Local Storage Only

All extension data — including rules, site configurations, and preferences — is stored entirely within your browser using chrome.storage.local. This data never leaves your device.

Content Scripts

The extension injects content scripts into web pages you visit. These scripts only scan input fields for sensitive content locally in your browser. No scanned content is transmitted externally.

Permissions

  • storage — Save and read extension settings locally
  • tabs — Broadcast configuration changes to open tabs

Third-Party Services

AI Guard does not integrate with any third-party services, APIs, or SDKs.

Changes to This Policy

If this privacy policy is updated, the changes will be published in the extension's source code repository.

Contact

For questions about this privacy policy, please open an issue at the extension's GitHub repository.
